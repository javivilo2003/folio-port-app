# Frontend (Next.js)

Planned stack:

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- shadcn/ui
- GSAP
- Spline exported 3D assets in `public/models/`

## Folder map

- `app/` routes and layouts
- `components/` reusable components
- `components/ui/` shadcn/ui components
- `animations/` GSAP timelines/helpers
- `hooks/` custom hooks
- `lib/` utils/config adapters
- `styles/` global and shared styles
- `types/` shared TS types
- `public/models/` Spline exports
- `public/textures/` 3D supporting assets
- `tests/` frontend tests
