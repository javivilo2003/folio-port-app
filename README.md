# Portfolio Frontend

Stack:

- Next.js (App Router) + React + TypeScript
- Tailwind CSS v4
- shadcn/ui

Commands:

```bash
npm run dev
npm run lint
npm run build
npm run start
```

Main folders:

- `app/` pages and layouts
- `components/ui/` shadcn components
- `components/sections/` page sections
- `animations/` GSAP timelines/helpers
- `public/models/` Spline exports
- `public/textures/` 3D textures
- `lib/` shared utilities
- `hooks/` reusable hooks
- `tests/` unit/integration/e2e
